# Runagotchi

Runagotchi is a React Native fitness application that combines workout tracking with a virtual pet system. User activity directly affects the wellbeing and growth of the pet.

## Features

- Workout tracking
- Virtual pet system
- Distance, pace, speed, and step tracking
- Weather-based environments
- In-game currency and accessories
- Statistics and graphs
- English UI

## Tech Stack

- React Native
- TypeScript / JavaScript
- GPS & Health APIs
- Weather API

## Installation

```bash
git clone <repository-url>
cd runagotchi
npm install
```

## Running the App

### Expo Go

```bash
npm expo start
```

### Android

```bash
npm run android
```

### iOS

```bash
npm run ios
```
